# autoCover

Generate blog cover images (OG images) from the command line.

**Features:** solid/gradient/image backgrounds · text boxes with rounded borders · logo placement · custom fonts · WebP/PNG/JPG output

## Installation

```bash
pip install -e .
```

This installs the `autocover` command. Dependencies are declared in `pyproject.toml`.

## Usage

```bash
autocover --title "TITLE" --subtitle "Subtitle" --footer "myblog.com" --output cover.webp
```

Full docs, all CLI options, usage examples and the changelog live on the
[project site](https://autocover.cuevaneander.tech).
