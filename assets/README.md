# Assets

Coloca tus archivos personalizados en cada directorio:

| Directorio | Contenido |
|---|---|
| `backgrounds/` | Imágenes de fondo (PNG, JPG, WebP) |
| `fonts/` | Fuentes personalizadas (TTF, OTF) |
| `logos/` | Logos (PNG con transparencia recomendado) |
| `overlays/` | Texturas u overlays opcionales |

## Uso rápido

```bash
python autocover.py \
  --background assets/backgrounds/bg.png \
  --font assets/fonts/MyFont.ttf \
  --logo assets/logos/logo.png \
  --logo-position bottom-left
```
